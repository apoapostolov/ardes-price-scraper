# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-28

### Added
- Initial release of Ardes Price Scraper
- Comprehensive price scraping from Ardes.bg configurator feeds
- SQLite database for price history storage with deduplication
- Timestamped CSV export functionality
- Price change analysis and markdown report generation
- Product search API with filtering by name, manufacturer, and category
- Command-line search interface
- TOML-based configuration system
- Windows batch file for easy execution
- Comprehensive test suite with pytest
- Makefile for Linux/macOS development workflows
